THRASHING THE CRYPTS WEBSITE

Open index.html in any browser.

Pages:
- index.html — Home
- meetups.html — meetup list + show-link form
- merch.html — merch storefront mockup
- about.html — About Us
- styles.css — all styling
- script.js — meetup storage/rendering
- assets/ — T.T.C. logo and skeleton artwork

MEETUP LINKS:
On meetups.html, the “Show / ticket link” field accepts a normal https:// link.
The meetup cards then show a “Show / Tickets” button.

IMPORTANT:
The meetup form uses localStorage. That means meetups are visible only in the browser/device where they were entered.
For a public live site, connect it to a shared backend or form/database service.
